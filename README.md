# Learning-Power-BI-Desktop
This repository houses various resources for the course, and these resources may be referenced in the course videos. It IS NOT NECESSARY to follow along with all these files during the lessons. The files are provided just in case you want to try a few things out for yourself.

Here is a description of each of the directories:

**Data** Contains the raw data files that are used to populate the Power BI pbix files. Put the folder at a locaiton that you are able to easily access. 

**Note:** Some lessons use a SQL Server Database, and a SharePoint Online list, plus a few other sources. It is recommended to just watch any lessons that use data that IS NOT in the Data directory as no guidance or instructions are given on how to do this, and it is not worth your effort.
